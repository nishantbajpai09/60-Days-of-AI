# Road Accident Insight Explorer

An interactive web app that turns raw UK road accident data into insights anyone can explore — no SQL, no Power BI, no training required. Open a link, apply a filter, instantly see where, when, and why accidents happen.

## Features

- **Filters** — severity, weather condition, police force area, and date range, applied instantly
- **Hotspot map** — density-based heat map (yellow → orange → red) showing where accidents cluster
- **Trend charts** — accidents by hour of day, by day of week, and severity breakdown
- **Auto-generated insights** — plain-language takeaways from the currently filtered data

## Tech stack

- [Streamlit](https://streamlit.io) — Python-only app, no separate frontend/backend
- [pandas](https://pandas.pydata.org) — data cleaning and transformation
- [Plotly](https://plotly.com/python/) — charts and the hotspot map (density mapbox)
- Parquet file storage — no database server required
- [Streamlit Community Cloud](https://streamlit.io/cloud) — free hosting

## Data source

[UK Road Safety Open Data (STATS19)](https://www.data.gov.uk/dataset/cb7ae6f0-4be6-4935-9277-47e5ce24a11f/road-safety-data), Department for Transport, released under the [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).

## Running locally

1. Clone this repo and move into the folder:

   ```
   git clone https://github.com/<your-username>/road-accident-insight-explorer.git
   cd road-accident-insight-explorer
   ```

2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

3. Download the [STATS19 collision CSV](https://www.data.gov.uk/dataset/cb7ae6f0-4be6-4935-9277-47e5ce24a11f/road-safety-data) and save it in this folder as `accidents_raw.csv`.

4. Run the ETL script to clean the data:

   ```
   python etl.py
   ```

5. Launch the app:

   ```
   streamlit run app.py
   ```
